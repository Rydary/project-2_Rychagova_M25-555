## Основные возможности

- Создание таблиц с указанием типов данных (`int`, `str`, `bool`)
- Добавление записей с автоматическим присвоением ID
- Фильтрация данных с помощью `where`
- Обновление данных с помощью `set`
- Удаление записей по условию
- Отображение таблиц в виде ASCII-таблиц через **PrettyTable**

## Описание и реализация функций

### 1. `insert(metadata, table_name, values)`
**Назначение:**  
Добавляет новую запись в указанную таблицу.  
Автоматически создаёт поле `ID` и проверяет типы данных.

### 2. `select(table_data, where_clause=None)`
Назначение:
Выбирает строки из таблицы, соответствующие условию фильтрации (where_clause).
Если условие не задано — возвращает все записи таблицы.

### 3. `update(table_data, set_clause, where_clause)`
Назначение:
Обновляет значения в таблице, соответствующие заданному условию.
Количество обновлённых строк выводится в консоль.

### 4. `delete(table_data, where_clause)`
Назначение:
Удаляет записи, удовлетворяющие условию.
Без where операция не выполняется для защиты от удаления всех данных.

### Работа декораторов

### 1. `handle_db_errors`

Декоратор для отлавливания ошибок, возникающих при работе с базой данных.  
Используется для предотвращения падения программы при неожиданных исключениях.

### 2. `confirm_action(action_name)`
Декоратор с аргументом, который спрашивает подтверждение у пользователя перед выполнением "опасного" действия, например удаления таблицы или записи.

### 3. `log_time`
Декоратор для замера времени выполнения функции.
Использует time.monotonic() и выводит время работы в консоль.

### 4. `create_cacher()`
Функция с замыканием для кэширования результатов.
Позволяет хранить результаты вызова функций и повторно использовать их без повторного вычисления.
